## Changes Validated

- Calculator routes now keep visible calculator `h1` and `h2` headings on the body font, matching the existing route-level decision not to preload the 67 KB Fraunces display font on calculators.
- The body font is preloaded globally so above-the-fold body-font LCP text does not depend on late font discovery.
- Homepage recent cards no longer eager-load below-fold article thumbnails during the initial mobile render. They use the existing lightweight category placeholder in that context.
- Homepage hero support copy was tightened so the first viewport remains focused on the route's primary value proposition.

## Regression Notes

- Public routes were not changed.
- Calculator formulas and inputs were not changed.
- The calculator trust badge order was tested as an intermediate experiment and reverted because it regressed LCP.
- The homepage `backUrl` session write was removed because the default back-button fallback already resolves to `/`; this avoids a noncritical homepage-only inline script.
