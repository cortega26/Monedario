# Docs Archive

Historical plans, backlogs, reports, and internal notes that are no longer active
but remain useful as audit trail.

- Backlog and roadmap snapshots: `docs/archive/backlog/`
- Historical development notes: `docs/archive/development/`
- Legacy internal docs: `docs/archive/internal-docs/`
- Closed operation records: `docs/archive/operations/`

Do not use archived material as current policy unless a live document links to it
explicitly.
