# Criterio obligatorio para evaluación de viabilidad (2026-05-13)

Toda recomendación sobre la viabilidad de una funcionalidad, producto o automatización en Monedario debe cumplir este criterio:

- El análisis debe ser realista y riguroso, considerando:
  - Acceso y disponibilidad pública de los datos requeridos
  - Restricciones legales, regulatorias o de uso
  - Factibilidad técnica real (no solo teórica)
  - Contexto y necesidades del negocio
- No asumir viabilidad solo por posibilidad técnica: si un factor crítico (ej. datos no públicos) lo impide, la respuesta debe ser NO viable, con explicación clara.
- La recomendación debe ser honesta, fundamentada y sin sesgo de optimismo injustificado.
- Si la viabilidad depende de condiciones externas inciertas, explicitarlo y sugerir alternativas o pivotes.

Este criterio es obligatorio y debe ser revisado antes de iniciar cualquier desarrollo o automatización que dependa de fuentes externas.
