# Codebase Docs

Esta carpeta concentra la orientacion rapida del repositorio para contributors y agentes.

## Orden recomendado de lectura

1. `STRUCTURE.md` — mapa operativo de carpetas y gates
2. `ARCHITECTURE.md` — capas, módulos y flujo de build
3. `TESTING.md` — harness de pruebas y convenciones
4. `INTEGRATIONS.md` — dependencias externas (Mindicador, Pagefind, etc.)

## Relacion con la documentacion canonica

Esta carpeta describe la forma actual de la implementacion.

Las reglas normativas y de autoridad siguen viviendo en:

- `docs/AI_ENGINEERING_CONSTITUTION.md`
- `AGENTS.md`
- `context/INVARIANTS.md`
- `context/CONTRACTS.md`

## Cobertura

- `STRUCTURE.md` — mapa operativo del código y de los gates
- `ARCHITECTURE.md` — modelo de capas, módulos de dominio, flujo de build
- `TESTING.md` — runner, estructura de tests, convenciones de cobertura
- `INTEGRATIONS.md` — dependencias externas, Mindicador, variables de entorno
