# Codebase Docs

Esta carpeta concentra la orientacion rapida del repositorio para contributors y agentes.

## Orden recomendado de lectura

1. `STRUCTURE.md` — mapa operativo de carpetas y gates
2. `STACK.md` — stack efectivo de runtime, tooling y build
3. `ARCHITECTURE.md` — capas, módulos y flujo de build
4. `CONVENTIONS.md` — reglas visibles de trabajo, testing y documentacion
5. `TESTING.md` — harness de pruebas y convenciones
6. `INTEGRATIONS.md` — dependencias externas (Mindicador, Pagefind, etc.)
7. `CONCERNS.md` — fricciones y riesgos visibles para mantenimiento

## Relacion con la documentacion canonica

Esta carpeta describe la forma actual de la implementacion.

Las reglas normativas y de autoridad siguen viviendo en:

- `docs/AI_ENGINEERING_CONSTITUTION.md`
- `AGENTS.md`

- `STACK.md` — runtimes, frameworks, librerias y tooling
